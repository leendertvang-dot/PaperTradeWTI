## Boundaries and cautions

- The browser smoke tests supplied **synthetic mock-feed data**. The screenshot inside the repository is illustrative, not a market quote or validated strategy performance.
- Real Hyperliquid or Gamma responses, CORS behavior and GitHub Pages online deployment were **not** end-to-end exercised in this release environment. Public API access and scheduling may change.
- `para:10Y` is displayed as a **separate reference** and is not an input to the WTI formula. The WTI quote engine is driven by public WTI best bid/ask, Polymarket Hormuz probability changes and inventory limits. Other displayed telemetry (e.g., OBI) is provided as context, not claimed as a direct strategy weight.
- Paper fills are exchange-print touch approximations; there is no queue priority, latency model or guaranteed executable edge.
- GitHub does not remove old leaked credentials from Git history merely because a new clean ZIP is uploaded. Rotate anything previously exposed.
